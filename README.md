## 🎯 O que é o Copilot YLabs

Coleção de **casos práticos** para treinamentos de adoção de IA e Copilot. Cada laboratório é um agente real, construído passo a passo, com **fluxograma, guia de construção e trilha de evolução** — pronto para replicar em sala ou no cliente.

> **Filosofia:** um mesmo caso de negócio, mostrado nas diferentes superfícies de criação de agentes, para o aluno **sentir a fronteira de cada ferramenta**.

## 📂 Laboratórios disponíveis

### ⚙️ Copilot Studio
- **copilot-studio/ferias-aprovacao/** — caso genérico. Agente que coleta os dados, dispara uma aprovação (Teams + e-mail) e responde o resultado. Construído em **3 modelos**: clássico, novo com tópico e novo sem tópico (generativo). 🟢
